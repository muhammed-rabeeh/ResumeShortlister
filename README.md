# Resume Shortlister — Installable AI Resume Modifier PWA

## Included PWA Files
- `index.html` — Responsive Desktop (1440px 12-col Split-Screen) & Mobile (375px–430px with 60px Glassmorphic Bottom Nav) Web Application
- `manifest.json` — W3C Web Application Manifest for native Android/iOS/Desktop installation
- `sw.js` — Offline-first Cache + Network fallback Service Worker
- `icons/icon-192.png`, `icons/icon-512.png`, `icons/icon-maskable-512.png`, `icons/apple-touch-icon.png` — High-DPI app icons

## Running & Installing on Mobile Devices
1. Serve the folder over HTTPS or localhost (e.g., `npx serve .` or deploy to Vercel / Netlify / GitHub Pages).
2. Open the URL in Chrome (Android) or Safari (iOS) and tap **Install App** / **Add to Home Screen**.
